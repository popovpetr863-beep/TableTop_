# Tabletop Hub
Единый сайт для дружеских онлайн-партий в Переворот, Каркассон и Орифламма.

## Запуск
Node.js 20+: `npm install` затем `npm start`.
Открыть `http://localhost:3000`.

Комнаты имеют код. Для ссылки используется `https://ВАШ-ДОМЕН/?room=КОД`; на хостинге можно копировать такую ссылку из браузера.

Это самостоятельная любительская реализация с собственной графикой и формулировками. Перед коммерческим публичным запуском проверьте права и товарные знаки соответствующих настольных игр.
